# 霁风的小圈 · 设计预览

[打开在线预览](https://jialep38-png.github.io/my-world-blog-redesign-preview/)

这是个人博客下一版的独立视觉样机，用于确认排版、配色和动效。原站 [2006038.xyz](https://2006038.xyz/) 与原仓库的部署保持不变。

## 先看这些

- 首页：开场动画、大字与花田、横向内容章节、橙色索引方块、丝线转场、点云扩散与聚合。
- 顶部导航：随笔、项目、小星球、关于使用不同整页底色，共用一种换页动画。
- 随笔第一篇：查看阅读页的中文字体、行宽与目录。
- 桌面留白区域：移动鼠标出现图片轨迹；文字和操作区域不触发。
- 手机：内容纵向排列；系统开启「减少动态效果」后，阅读优先。

首屏与中文界面使用 Noto Sans SC，文章与部分标题使用 Noto Serif SC，英文项目封面搭配 Instrument Serif 斜体。字体已按样机字符压缩并随站点托管，访问时不依赖外部字体服务。

## 预览范围

提供首页、随笔、项目、小星球、关于和一篇阅读页的代表画面。文章与作品使用已有博客的真实素材；其余详情链接进入现有正式博客。完整内容迁移、搜索、主题切换、三维浏览等将在视觉验收后的 Astro 集成中完成。

这一仓库不配置自定义域名，不向原博客仓库推送。页面设置了 `noindex`，供视觉评审使用。

## 本地预览

在本目录运行：

```sh
python -m http.server 8847 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8847/`。这是原生 HTML、CSS 与 JavaScript 样机，不需要安装前端依赖或执行构建。

更新页面文字后，可运行 `python scripts/prepare-fonts.py` 重新生成字体子集。此维护步骤需要网络，网站运行不需要它。

## 素材与字体

花田和五颗星球图像来自 [原博客仓库](https://github.com/jialep38-png/my-world-blog)，保留原有权利。参考站仅用于研究构图与动效，没有包含其品牌素材、模型或商业字体。点云由本仓库 Canvas 代码生成。

三款字体均按 SIL Open Font License 1.1 分发，版权信息、完整许可证与下载来源保存在 [fonts](fonts/) 目录。
